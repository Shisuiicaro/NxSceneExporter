# Nexus Scene Exporter

Exports portable `.nxscene` packages for local Nexus use. Export strips scripts from copies, preserves the source scene, and leaves static objects separate.

Install through Unity Package Manager with:

`https://github.com/Shisuiicaro/NxSceneExporter.git?path=/Packages/com.nexus.nxscene-exporter#main`

The GitHub release includes `NxSceneExporter.zip`, containing the UPM package. Each published release tag must match the package version, such as `v2.1.0` for package version `2.1.0`.

Marketplace catalog metadata, signing, encryption, and publishing are handled by Nexus owner tools.
